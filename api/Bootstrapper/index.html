Bootstrapper

A lightweight, agnostic module loader and scheduler for Roblox. Define exactly what runs, and in what order, every single frame.

Functions​

setProfiling​

</>
Bootstrapper.setProfiling(
enabled: boolean--

Whether bound methods are profiled.

) → ()

Enables MicroProfiler labels and memory categories for every bound method. Disabled by default for performance. Loading, run and spawn always set memory categories.

run​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
Bootstrapper.run(
modules: {Instance | LoadedModule},--

An array of ModuleScripts, Folders, or loaded modules.

methodName: string,--

The method to call. Prefix with '.' for standard calls; otherwise, the module is implicitly passed as 'self'.

...: any--

Additional arguments to pass to the method.

) → LoadedModules,Errors?

Calls methods one-by-one and yields until complete. Guarantees that Module A is finished before Module B starts. Returns every loaded module except those whose method errored, so the result can be passed to the next stage. Warns if still yielding after 10 seconds. Use spawn for methods that never return.

runConcurrent​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
Bootstrapper.runConcurrent(
modules: {Instance | LoadedModule},--

An array of ModuleScripts, Folders, or loaded modules.

methodName: string,--

The method to call. Prefix with '.' for standard calls; otherwise, the module is implicitly passed as 'self'.

...: any--

Additional arguments to pass to the method.

) → LoadedModules,Errors?

Calls all methods simultaneously using multiple threads and yields until all are complete. Methods start in order, but order of completion is not guaranteed. Returns every loaded module except those whose method errored, in their original order. Warns if still yielding after 10 seconds. Use spawnConcurrent for methods that never return.
